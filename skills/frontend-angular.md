# Frontend — Angular / TypeScript

## Уровень

Senior: Standalone components, Signals, RxJS, сложные UI на Material / PrimeNG.

## Стек

- Angular 16+ (в т.ч. Angular 21 на VineTrack / CoopMonitor)
- TypeScript, Standalone API, Signals (zone-less ready)
- RxJS
- Angular Material, PrimeNG
- SCSS, Tailwind
- Vite (где применимо)
- Тесты: Vitest, Cypress (E2E) — в проектах портфолио

## Где применялось

- VineTrack — Angular 21 SPA: GIS Dual-View, агро/погреб/traceability, Dexie offline, SSR QR-паспорт
- ChickenYard / CoopMonitor — мониторинг и RBAC UI
- Interactive Portfolio — Signals + real-time уведомления
- Role-Play / English Tutor — клиенты AI-продуктов

## Практики

- Реактивный UI на Signals
- Строгая типизация API-клиентов
- Разделение feature-модулей / standalone routes
