# Архитектурные паттерны и принципы

1. **Clean Architecture / Onion** — API, Domain, Application, Infrastructure (Interactive Portfolio, Role-Play, VineTrack).
2. **Microservices & Event-Driven** — RabbitMQ для тяжёлых асинхронных задач (Interactive Portfolio); сервисная декомпозиция CoopMonitor.
3. **MVVM** — WPF (HikrobotScanner, Crossword) и аналог через Angular services.
4. **DI / Service Locator** — стандартный DI в .NET/Angular; кастомные контейнеры в Unity.
5. **Automated Code Generation** — generate_full_stack, OpenAPI TypeScript clients — ускорение boilerplate.
6. **No-DB / document-first** — English Tutor, Life OS v2: Markdown как источник правды для людей и AI.
7. **Multi-Agent systems** — оркестратор + специализированные агенты (Role-Play, AI Coder).
