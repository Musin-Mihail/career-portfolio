# Life OS (техническое описание)

## Суть

Персональный life/analytics hub: сбор входных данных → AI-отчёты и планы. **В портфолио описывается только как технический продукт; личные данные не публикуются.**

## Стек

- Python, Streamlit
- pandas / plotly (аналитика)
- Google Gemini
- Markdown «базы» (Life_OS_v2)

## Highlights

- Пайплайн parse → report
- Документ-ориентированное хранение планов/метрик
- Итеративные ТЗ и планы (v1–v7)

## Где код / данные

Исходники и персональные базы — в отдельном приватном репозитории; в портфолио только техническое описание продукта.
