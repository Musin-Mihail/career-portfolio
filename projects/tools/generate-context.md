# generate_context

## Суть

Утилита упаковки кодовой базы в LLM-контекст по JSON-конфигам (фильтры путей, лимиты, цели: VineTrack, ChickenYard и др.).

## Стек

- Python
- JSON-конфиги на проект

## Зачем в портфолио

Ключевой DX-инструмент для AI-assisted разработки: воспроизводимый context packing вместо ручного копирования файлов.

`ai-dev-toolkit/generate_context/`
