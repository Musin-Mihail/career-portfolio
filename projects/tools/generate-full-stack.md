# generate_full_stack

## Суть

Кодогенератор boilerplate для связки Backend (C# Controller/Service) + Frontend (Angular Service/Component) по декларативному описанию.

## Стек

- Python
- Шаблоны под связку ASP.NET Core + Angular (enterprise / portal UI)

## Зачем в портфолио

Демонстрирует DX-мышление: ускорение рутинной разработки за счёт собственной генерации слоёв full-stack.

## Где код

Отдельный DX-репозиторий (не публичный). Описание без внутренних путей работодателя.
