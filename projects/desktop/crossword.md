# Техническая спецификация проекта: Crossword Generator

## 1. Общие сведения

**Crossword Generator** — это десктопное приложение (WPF), разработанное на платформе .NET 6. Приложение предназначено для проектирования сеток кроссвордов с использованием инструментов симметрии и их автоматического заполнения словами из подключенных словарей с использованием алгоритма с возвратом (backtracking).

- **Платформа:** .NET 6 (Windows)
- **Фреймворк UI:** WPF (Windows Presentation Foundation)
- **Архитектурный паттерн:** MVVM (Model-View-ViewModel)
- **Код:** [github.com/Musin-Mihail/Tool_Crossword_Generator](https://github.com/Musin-Mihail/Tool_Crossword_Generator)

- **Внедрение зависимостей:** `Microsoft.Extensions.DependencyInjection`

- **Графика (экспорт):** `System.Drawing.Common` (GDI+)

---

## 2. Архитектура и Структура проекта

Проект организован согласно принципам Clean Architecture / MVVM. Точкой входа является `App.xaml.cs`, где происходит конфигурация DI-контейнера (`ServiceCollection`) и регистрация всех сервисов, ViewModel и View .

### 2.1. Инфраструктура

- **`RelayCommand`:** Реализация `ICommand` для связывания действий UI с методами ViewModel. Поддерживает делегаты `Execute` и `CanExecute`.

- **`ViewModelBase`:** Базовый класс для всех VM, реализует `INotifyPropertyChanged`. Содержит метод `SetProperty<T>` для удобного обновления полей с уведомлением интерфейса .

---

## 3. Модели данных (Domain Models)

Основные сущности, описывающие состояние кроссворда и данные словарей.

- **`Cell` (Ячейка):**
- Хранит координаты `X`, `Y` и содержимое (букву) `Content`.
- Является легковесной моделью для логики генерации, в отличие от `CellViewModel`.

- **`Word` (Слово на сетке):**
- `Cells`: Список ячеек, образующих слово.
- `ConnectionWords`: Список слов, пересекающихся с данным.
- `ConnectionCells`: Конкретные ячейки пересечения.
- `FullDictionaries`: Отфильтрованные списки слов из словарей, подходящие по длине.
- `Right`: Булев флаг ориентации (True = горизонтально, False = вертикально).
- `Fix`: Флаг, указывающий, что слово взято из словаря "ОБЯЗАТЕЛЬНЫЕ" и не подлежит замене .

- **`Dictionary` (Словарь):**
- Содержит имя, список слов (`DictionaryWord`), максимальный лимит использования (`MaxCount`) и текущий счетчик использования.

- **`DictionaryWord`:**
- Хранит само слово (`Answers`) и список определений (`Definitions`).

## 4. Сервисный слой (Business Logic)

Вся бизнес-логика вынесена в сервисы, описанные интерфейсами в `Services.Abstractions`.

### 4.1. `GenerationService` (Ядро генерации)

Отвечает за алгоритмическое заполнение сетки.

- **Алгоритм:** Асинхронный перебор с возвратом (Backtracking).
- **Ключевые этапы:**

1.  **Анализ сетки:** Метод `InitializeWordGrid` сканирует пустые ячейки, определяет горизонтальные и вертикальные слоты для слов (`SaveWordRight`, `SaveWordDown`) и строит граф пересечений (`SearchForConnectedWords`) .

2.  **Предварительная фильтрация:** Для каждого слота создается локальный под-словарь (`CreateWordSpecificDictionaries`), содержащий только слова нужной длины.

3.  **Цикл подбора:**

- Перебирает слова по индексу.
- `FindMatchingWord`: Ищет слово в словаре, соответствующее текущей маске (паттерну) на сетке (учитывая уже вставленные буквы пересекающихся слов).

- `StepBack`: Если слово подобрать не удалось, алгоритм откатывается назад, очищая пересекающиеся слова и пытаясь перестроить ветку решений.

- **Визуализация:** Использует события (`VisualizeWordPlacement`) для анимации процесса подбора (зеленый — успех, красный — неудача) прямо на UI.

### 4.2. `GridManagerService` (Управление сеткой)

Отвечает за состояние сетки в UI и рисование.

- **Хранение:** Коллекция `ObservableCollection<CellViewModel>` для привязки к View.
- **Симметрия:** Реализует логику зеркального рисования стен (черных ячеек). Поддерживаемые режимы:
- Вертикальная / Горизонтальная симметрия.
- Полная (центральная) симметрия.
- Реверсивная симметрия (диагональная инверсия) .

- **Конвертация:** Преобразует `CellViewModel` (UI) в `Cell` (Model) для передачи в генератор.

### 4.3. `DictionaryService` (Работа с файлами)

- Загружает словари из папки `Dictionaries`.
- **Формат файла:** Текстовый файл, где каждая строка: `Слово;Определение1;Определение2...` .

### 4.4. `ScreenshotService` (Экспорт)

- Генерирует растровые изображения кроссворда используя `System.Drawing`.
- **Экспорт:**
- `EmptyGrid.png`: Сетка с нумерацией (для печати).
- `FillGrid.png`: Сетка с ответами.
- `Answer.txt` / `Definition.txt`: Текстовые файлы с вопросами и ответами .

- **Логика:** Рисует попиксельно прямоугольники и текст, рассчитывая координаты на основе `CellViewModel.X/Y` и размера ячейки (~37px).

## 5. Слой представления (ViewModels)

Логика UI разбита на специализированные ViewModel, объединенные в `MainViewModel`.

### 5.1. `MainViewModel`

Корневая ViewModel. Управляет состоянием доступности UI (`IsUiEnabled`) в зависимости от флага `IsGenerating` в `GenerationControls`.

### 5.2. `GridControlViewModel`

- Управляет инструментами рисования (симметрия, очистка).
- Содержит логику отображения линий центра (зеленые линии на Canvas) для удобства симметричного рисования .

- Обрабатывает клики по ячейкам через `HandleCellInteraction`.

### 5.3. `GenerationControlViewModel`

- Управляет параметрами генерации: тайм-аут на одно слово (`MaxSecondsText`), задержка визуализации (`TaskDelayText`).
- Подписан на события `GenerationService` для трансляции статуса и обновления ячеек в реальном времени через `Dispatcher` .

### 5.4. `FileControlViewModel` & `DictionaryControlViewModel`

- **FileControl:** Сохранение/загрузка шаблонов сеток (формат `.grid`) и вызов экспорта скриншотов.
- **DictionaryControl:** Выбор активных словарей, создание "обязательного" словаря, сброс к дефолтному (`dict.txt`).

## 6. Форматы данных и Ввод/Вывод

### 6.1. Файл словаря (.txt)

- **Кодировка:** Стандартная для `File.ReadAllLines`.
- **Структура строки:** Разделитель `;`.
- Индекс 0: Ответ (Слово).
- Индекс 1..N: Определения (Вопросы).

### 6.2. Файл сетки (.grid)

- Простой текстовый формат для сохранения структуры "стен".
- Содержит только координаты пустых (белых) ячеек.
- **Формат:** `X;Y` на каждой строке.

### 6.3. Результаты генерации

- Изображения генерируются с разрешением 300 DPI.

- Нумерация слов происходит автоматически: алгоритм сортирует слова по координатам начала (Y, затем X) и присваивает номера.

---

## 7. Особенности реализации UI

- **Рендеринг сетки:** Используется `ItemsControl` внутри `Canvas`. Позиционирование элементов `CellViewModel` осуществляется через привязку свойств `Canvas.Left` и `Canvas.Top` к вычисляемым свойствам `DisplayX` и `DisplayY` во ViewModel.

- **Интерактивность:** Обработка нажатий мыши (`MouseDown`, `MouseMove`) реализована через EventSetter в стиле элемента или напрямую в CodeBehind (`MainWindow.xaml.cs`), который делегирует команду во ViewModel.

- **Визуализация прогресса:** Прямая манипуляция свойствами `Background` и `Content` ячеек в `GenerationService` (через события) позволяет пользователю видеть, как алгоритм "думает" и перебирает варианты.
