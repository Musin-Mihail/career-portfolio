# Техническая спецификация проекта HikrobotScanner

## 1. Общие сведения

**HikrobotScanner** — это настольное приложение (Desktop Application) для операционной системы Windows, разработанное на платформе .NET 9 с использованием фреймворка WPF. Приложение предназначено для автоматизации процесса сбора данных с двух промышленных сканеров (камер) Hikrobot ID5000, их валидации, агрегации и сохранения, а также для генерации и печати служебных штрих-кодов.

**Код:** [github.com/Musin-Mihail/Tool_Hikrobot_Scanner](https://github.com/Musin-Mihail/Tool_Hikrobot_Scanner)

## 2. Технологический стек и Зависимости

### 2.1. Платформа и Язык

- **Target Framework:** `.NET 9.0` (`net9.0-windows`).

- **Язык программирования:** C# 12/13 (используются современные фичи: file-scoped namespaces, global usings).
- **UI Фреймворк:** Windows Presentation Foundation (WPF).

### 2.2. Архитектурные библиотеки

- **MVVM Pattern:** Реализован с помощью `CommunityToolkit.Mvvm` (версия 8.2.2).

- **Dependency Injection (DI):** `Microsoft.Extensions.DependencyInjection` (версия 8.0.0) для управления жизненным циклом сервисов.

### 2.3. Сторонние библиотеки и SDK

- **ZXing.Net:** (версия 0.16.10) — используется для программной генерации штрих-кодов (CODE-128).

- **MvCameraControl.Net.dll:** Нативная библиотека (SDK) от Hikrobot для управления камерами. Подключается как прямая ссылка (`Reference`), а не через NuGet.

## 3. Архитектура приложения

Приложение построено по принципам **MVVM (Model-View-ViewModel)** с чистым разделением ответственности и внедрением зависимостей через конструкторы.

### 3.1. Точка входа и DI-контейнер

- Класс `App` (`App.xaml.cs`) инициализирует `ServiceCollection`.
- Все основные сервисы регистрируются как **Singleton**: `IAppLogger`, `IDispatcherService`, `ISettingsService`, `IBarcodeService`, `IDataService`, `ICameraService`, `IServerService`.
- `MainViewModel` регистрируется как **Transient** .

### 3.2. Основные компоненты (Сервисы)

#### A. CameraService (`ICameraService`)

- **Назначение:** Управление физическими устройствами Hikrobot.
- **Функции:**
- Поиск подключенных устройств (`MV_CC_EnumDevices_NET`).
- Инициализация двух камер.
- Загрузка профилей настроек (UserSet) в камеры .

- Старт/Стоп захвата изображений (`StartGrabbing`).
- Корректное освобождение ресурсов (Cleanup).

#### B. ServerService (`IServerService`)

- **Назначение:** Прием данных от сканеров по сети.
- **Реализация:** Запускает два независимых асинхронных `TcpListener` на разных портах.
- **Логика:**
- Приложение выступает в роли **TCP Server**.
- Сканеры (камеры) подключаются как клиенты.
- Данные считываются асинхронно и передаются через callback `DataReceivedCallback` .

#### C. BarcodeService (`IBarcodeService`)

- **Назначение:** Генерация, печать и учет штрих-кодов.
- **Логика:**
- Хранит счетчик в локальном файле `barcode_counter.txt`.

- Формат генерируемого кода: Фиксированный префикс `004466005944` + 7 цифр счетчика + суффикс `9`.

- Использует `ZXing.Net` (`BarcodeWriterPixelData`) для рендеринга Code-128.
- Формирует `FlowDocument` для печати через стандартный `PrintDialog` WPF .

#### D. DataService (`IDataService`)

- **Назначение:** Сохранение результатов в файловую систему.
- **Формат сохранения:** Текстовые файлы (`.txt`) в директории `codes`.
- **Именование файлов:** `yyyyMMdd_HHmmss_{LinearCode}.txt`.

#### E. AppLogger (`IAppLogger`)

- **Назначение:** Централизованное потокобезопасное логирование событий.
- **Реализация:** Накапливает лог в `StringBuilder`, уведомляет UI через событие `LogUpdated` .

## 4. Бизнес-логика и Поток данных

Вся логика агрегации находится в `MainViewModel.cs`.

### 4.1. Сценарий сканирования

1. **Запуск:** Пользователь задает IP-адреса, Порты и UserSet для двух камер, нажимает "Старт сервера".
2. **Ожидание:** Приложение открывает порты и ждет подключения от камер.
3. **Прием данных:**

- Данные поступают асинхронно от Camera 1 и Camera 2.
- Используются буферы `_camera1DataBuffer` и `_camera2DataBuffer`.
- Обработка начинается только когда **оба** буфера заполнены.

4. **Валидация и Агрегация (`ProcessCombinedData`):**

- Данные объединяются через разделитель `#`.
- Строка разбивается на сегменты.
- **Поиск линейного кода:** Ищется сегмент длиной ровно 20 символов, состоящий из цифр.

- _Правило:_ Должен быть найден ровно один уникальный линейный код.

- **Поиск QR-кодов:** Все остальные сегменты считаются QR-кодами.
- _Правило:_ Количество уникальных QR-кодов должно быть не менее ожидаемого (настраивается: 6 или 8).

- **Проверка дубликатов:** Проверяется, не был ли этот линейный код уже обработан в текущей сессии (`_receivedCodes`).

5. **Результат:**

- Если валидно: Данные сохраняются в файл, лог обновляется.
- Если ошибка: Воспроизводится звуковой сигнал (3 бипа), экран мигает красным (`IsErrorState`), выводится MessageBox .

## 5. Пользовательский интерфейс (UI)

### 5.1. Структура MainWindow

- **Настройки подключения:** Grid с полями для IP, портов и ComboBox для выбора UserSet и кол-ва QR-кодов. Привязка `TwoWay` к `Settings` .

- **Управление:** Кнопки Start/Stop/Clear, привязанные к `RelayCommand` во ViewModel.
- **Генерация кодов:** Панель с отображением текущего счетчика и кнопкой печати.
- **Лог:** `TextBox` (Read-only) с автоматической прокруткой (`ScrollToEnd` в code-behind).

- **Визуальная индикация ошибок:** Прозрачный `Border` поверх всего окна (`ErrorFlashOverlay`), который запускает анимацию `ColorAnimation` (красный цвет), если свойство `IsErrorState` становится `True` .

### 5.2. Конфигурация (`App.config`)

Приложение использует `Properties.Settings` для хранения пользовательских настроек между запусками:

- IP-адреса камер (`CameraIp`, `CameraIp2`).
- Порты прослушивания (`ListenPort`, `ListenPort2`).
- Индексы профилей настроек (`UserSetIndex`, `UserSetIndex2`).
- Индекс ожидаемого количества частей (`ExpectedPartsIndex`) .

## 6. Ключевые алгоритмы

### Алгоритм парсинга (MainViewModel.cs)

```csharp
var parts = rawString.Split('#');
foreach (var part in parts) {
    if (part.Length == 20 && IsDigits(part)) -> LinearCode
    else -> QRCode
}

```

### Алгоритм генерации штрих-кода (BarcodeService.cs)

```csharp
Format: "004466005944" + Counter.ToString("D7") + "9"

```

## 7. Файловая структура и Развертывание

Для корректной работы приложения в папке с исполняемым файлом должны находиться:

1. `HikrobotScanner.exe` (и сопутствующие dll .NET).
2. `MvCameraControl.Net.dll` (нативная библиотека, копируется вручную или скриптом, не через NuGet).

3. Папка `codes` (создается автоматически для логов сканирования).
4. Файл `barcode_counter.txt` (создается автоматически для хранения состояния счетчика).
